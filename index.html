Rclone-Drive-Pessoal-Pro

Integração pessoal, não comercial, que utiliza o software rclone para realizar cópias de segurança de uma pasta local para contas Google Drive expressamente autorizadas pelo titular.

O aplicativo não oferece acesso público aos arquivos. O site serve apenas para identificar o projeto de autenticação OAuth.

O acesso ao Google Drive é realizado diretamente pelo rclone instalado no computador do titular, sujeito às permissões concedidas no Google.
